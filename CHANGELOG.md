# Changelog

## 1.0.0 - 2026-10-13

First release.

- `switchman` skill, run manually with `/switchman <task>`.
- `switchman-init` skill, builds the routing table from the installed skills.
- Example routing table for design, bugs, features, code review, security and writing.
- Install as a Claude Code plugin, with `npx skills add`, or by copying two folders.
